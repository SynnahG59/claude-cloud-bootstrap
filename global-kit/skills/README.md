# Allgemeine Skills

Jeder Skill bekommt einen eigenen Ordner mit einer `SKILL.md`:

```
skills/
  mein-skill/
    SKILL.md
```

`SKILL.md` beginnt mit einem Frontmatter-Block:

```
---
name: mein-skill
description: Wann der Skill benutzt werden soll.
---
Anleitung ...
```

Projektspezifische Skills gehoeren NICHT hierher, sondern ins jeweilige Projekt-Repo.
Dieses Repo ist oeffentlich: keine Zugangsdaten, keine persoenlichen Inhalte.
